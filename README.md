# SmartDayPlanner

SmartDayPlanner, kullanıcıların günlük görevlerini planlamasına ve yapay zeka desteğiyle mevcut planlarını optimize etmesine yardımcı olan Android tabanlı bir kişisel planlama uygulamasıdır.

## Özellikler

* Görev ekleme, düzenleme ve silme
* Görevlere tarih, süre ve öncelik atama
* Sabah / Öğle / Akşam kategorileri
* Çoklu seçim ve toplu silme
* Yapay zeka ile günlük plan oluşturma ve güncelleme
* Görevlerin cihazda kalıcı olarak saklanması

## Kullanılan Teknolojiler

* Java
* Android Studio
* XML
* RecyclerView
* SharedPreferences
* Gson
* Groq API

## Çalışma Mantığı

Kullanıcı görevlerini manuel olarak oluşturabilir veya yapay zekaya planlama isteği verebilir. Yapay zeka mevcut görevleri analiz ederek ilgili gün için optimize edilmiş bir plan oluşturur ve gerektiğinde günceller.

## Mevcut Durum

Uygulama temel görev yönetimi ve yapay zeka destekli planlama özellikleriyle çalışır durumdadır. Görevler düzenlenebilir, silinebilir ve yapay zeka tarafından yeniden planlanabilir.

## Gelecek Geliştirmeler

* Takvim entegrasyonu
* Bildirim sistemi
* Tarih aralıklı görevler
* Verimlilik analizi
* Room Database desteği
